# Short-Term Rental Guest Message Templates: What to Send and When

Most guest friction comes from silence or vague replies. These are the messages that prevent the most problems, with the timing that works.

## 1. Booking confirmation (send within an hour)

Confirm the dates, check-in window, and how to find the property. Guests who get this early ask fewer questions later.

## 2. Check-in instructions (send 24 hours before arrival)

- Exact door code or lockbox location, and when it activates
- Parking rule (where, how many cars)
- Wi-Fi name and password
- Who to contact if the code fails, with a phone number

Put the code in the message, not in a PDF link. Guests often cannot open attachments on arrival day.

## 3. Mid-stay check-in (day 1 or 2)

A single line asking whether anything is missing. It catches broken appliances while you can still fix them, before the guest writes a bad review.

## 4. Early checkout reminder (morning of departure)

State the checkout time, where to leave keys, and the one or two things you need done (trash out, dishwasher run). Keep it to four lines.

## 5. Review request (24 hours after checkout)

Ask once, politely, and make it easy. Do not offer anything in exchange for a review; that breaks platform rules on most booking sites.

## Rules that apply to every message

- Send the same message to every guest for the same stage. Consistency reduces disputes.
- Write the time zone when you give a time.
- Keep a copy of each message you send. If a guest claims you never told them something, you can show it.
